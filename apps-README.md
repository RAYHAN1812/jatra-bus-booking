# Jatra Travel Lab

Open `apps.html` to use three browser-based travel tools:

1. **Weekend Escape Finder** — suggests a destination in Bangladesh based on travel mood, starting city, trip length and budget. Destination costs are indicative estimates only.
2. **Group Trip Splitter** — calculates a simple equal share across transport, accommodation, food, activities and other expenses.
3. **Smart Packing Planner** — builds a checklist based on trip length and travel style, tracks checked items and lets you add custom items.

## Tech

Vanilla HTML, CSS and JavaScript. No framework, backend, external API, or build step is required. The tools run in the browser and do not send expense or packing data to a server.

## Notes

Destination availability, prices, transit schedules, weather, and local access are not live-verified. Always confirm plans before travelling. The expense splitter assumes all expenses are shared equally; it does not track who paid each bill or transfer funds.
